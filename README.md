# SMG Plombier

Site vitrine Next.js pour SMG Plombier, plombier à Douala et Yassa.

## Développement local

Prérequis : Node.js 20+.

```bash
npm install
npm run dev
```

Le site démarre sur `http://localhost:3000`.

## Déploiement Vercel

Utiliser le preset `Next.js`, le dossier racine du dépôt, et la commande de build :

```bash
npm run build
```

Les images locales sont servies depuis `public/images` et référencées avec des chemins absolus comme `/images/logo.png`.
